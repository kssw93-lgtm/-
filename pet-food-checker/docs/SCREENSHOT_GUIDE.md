# 스크린샷 촬영 가이드 (Toss 미니앱 제출용)

Toss 미니앱 심사 제출 시 필요한 스크린샷 5장 가이드입니다.
해상도: **1080x1920 (모바일 세로)** 권장.

촬영 방법: 크롬 개발자도구 → 기기 툴바(Ctrl+Shift+M) → iPhone 12 Pro 또는
커스텀 1080x1920 설정 후 `npm run dev`로 로컬 서버를 띄우고 캡처합니다.

## 1. 메인 화면 (검색 전)
- 검색창 + 필터 버튼 + 전체 음식 리스트가 보이는 초기 화면
- 강아지 이모지 헤더가 잘 보이도록 상단 여백 포함

## 2. 검색 중 화면
- 검색창에 "초콜릿" 입력 후 결과가 필터링된 화면
- 치명적(빨강) 카드가 강조되어 보이도록 구성

## 3. 필터 사용 화면
- 상단 필터에서 "안전" 탭을 선택한 상태
- 초록색 안전 카드 여러 개가 보이는 화면

## 4. 상세 정보 펼침 화면
- 카드를 탭하여 증상/대처/적정량 정보가 펼쳐진 상태
- 위험 성분, 증상, 대처 방법이 모두 보이도록 캡처

## 5. 4단계 안전도 한눈에 보기
- 치명적/위험/주의/안전 카드가 골고루 섞여 보이는 스크롤 화면
- 색상 구분이 잘 드러나는 구간 선택
