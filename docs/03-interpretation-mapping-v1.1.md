01. 특징값 추출 규칙

MVP 단계에서는 두 가지 축만 사용한다. 이후 궁합·재회운 등을 추가할 때 축을 더 늘릴 수 있다.

축 1. 십신 강세 유형 (5종)

원국(년/월/일/시 8글자 + 지장간)에 나타난 십신 중 개수가 가장 많은 그룹을 기준으로 분류한다.

그룹	해당 십신	개수 집계 대상

비겁형	비견, 겁재	천간 4개 + 지장간 전체
식상형	식신, 상관	〃
재성형	편재, 정재	〃
관성형	편관, 정관	〃
인성형	편인, 정인	〃


동률일 경우 우선순위: 비겁 > 식상 > 재성 > 관성 > 인성 (원국의 일간과 같은 오행에 가까운 순서로 임의 고정. 추후 조정 가능)

축 2. 일간 강약 (2종)

신강 / 신약

[v1.1 수정] 계산 규칙서 v2.0 45번은 "오행 단순 개수만으로 신강·신약을 결정하지 않는다"고 명시한다. v1.0에서 쓴 "비겁+인성 십신 개수 50% 이상" 기준은 이 원칙을 위반하는 단순 개수 판정이었으므로 폐기하고, 아래와 같이 계산 규칙서 45번이 지정한 원자료(월령·통근·생조/극설 관계)를 사용한 점수제로 교체한다.

입력 원자료 (계산 엔진이 제공, 45번 참조):
- month_branch (월지)
- day_stem (일간)
- rootedness (통근 여부, 지지별)
- stem/branch elements (천간·지지 오행)
- hidden_stems (지장간)

점수 산정:

① 득령(得令) — 월지의 오행이 일간을 생조(비겁 또는 인성 관계)하면 30점, 아니면 0점
② 득지(得地) — 일지의 지장간 중 일간을 생조하는 것(비겁·인성)이 있으면 20점, 아니면 0점
③ 득세(得勢) — 일간을 제외한 나머지 천간 3개 + 지지 3개(월지·일지 제외) 총 6개 중, 일간을 생조하는(비겁·인성 오행) 것의 개수 × 8점 (최대 48점)

총점 = ① + ② + ③ (최대 98점)

판정: 총점 50점 이상 → 신강 / 50점 미만 → 신약

주의: 이 점수제는 격국·조후 등을 포함한 정통 억부론의 완전한 대체가 아니라, "규칙서가 지정한 원자료만 사용"하는 조건을 지키면서 서비스에 필요한 이진 분류(신강/신약)를 만들기 위한 실용 규칙이다. 계산 엔진의 계산 결과(원국 데이터)는 건드리지 않고, 그 위에서 해석 엔진 역할로만 동작한다.

축 1(5종) × 축 2(2종) = 총 10개 패턴

01-1. [신설] 출생시간 미상 시 예외 규칙

계산 규칙서 v2.0 4번: "시간 미상인 경우 시주는 확정하지 않는다. AI가 임의로 시주를 추정하지 않는다."

이에 따라 특징값 추출도 시주를 사용할 수 없다. 처리 규칙:

- 축 1(십신 강세 유형) 집계 대상에서 시간·시지·시지 지장간을 제외하고, 년주·월주·일주(천간 3개 + 지지 3개 + 해당 지장간)만으로 집계한다.
- 축 2(신강/신약) 점수제의 "③ 득세" 항목에서 전체 모집단이 6개(천간3+지지3)에서 4개(천간2+지지2, 일간·일지 제외분)로 줄어든다. 배점은 비율을 유지하도록 개당 12점으로 조정한다(4개 × 12점 = 48점, 기존과 동일한 최대치 유지).
- 결과 화면에는 "출생시간을 몰라 시주를 제외하고 계산했다"는 안내 문구를 별도로 노출한다(템플릿 문구는 08번 참조).
- 이 예외 처리는 화면 흐름 설계서의 미결사항 ①에 대한 답이기도 하다.

03. 운세 카테고리 (MVP)

love (연애운)
career (직업운)

각 카테고리는 10개 패턴 × 버전(최소 2개) = 최소 20개 템플릿을 갖는다.
버전을 두는 이유: 같은 패턴이어도 매번 똑같은 문장이 나오면 "재방문 시 뻔하다"는 인상을 주므로, 노출 시 버전 중 하나를 선택한다.


---

04. 버전 선택 규칙

동일 인물이 같은 카테고리를 다시 볼 경우 결과가 계속 바뀌면 신뢰도가 떨어지므로, 완전 랜덤이 아니라 아래 방식을 권장한다.

seed = hash(생년월일시 + 카테고리)
version_index = seed % 버전개수

즉 같은 사람 + 같은 카테고리는 항상 같은 버전이 나오고, 사람이 다르면 자연스럽게 버전이 분산된다.


---

05. 변수 치환 규칙

템플릿 안에서 사용 가능한 변수:

{이름} → 사용자가 입력한 이름
{일간_한자} → 일간 한자 (예: 甲)
{일간_한글} → 일간 음독 (예: 갑목)

변수가 없는 입력(익명 이용 등)일 경우 {이름} 자리에는 "당신"으로 대체한다.

06. 인트로 대사 세트

캐릭터가 카테고리 선택 직후, 정보 입력 화면 전에 보여주는 짧은 도입 멘트. 결과 자체와는 무관하며 버전은 무작위로 노출해도 무방하다.

10. 확장 원칙

향후 재회운·재물운·결혼운·종합운을 추가할 때도 동일한 10패턴 구조를 그대로 재사용한다.

카테고리 추가 시 필요한 작업은 다음 두 가지뿐이다.

① 해당 카테고리의 인트로 대사 2개 작성
② 해당 카테고리의 10패턴 × 2버전 = 20개 템플릿 작성

계산 엔진·특징값 추출·패턴 분류 로직은 전혀 손댈 필요가 없다. 즉 카테고리를 늘릴수록 개발 작업이 아니라 "카피라이팅 작업"만 늘어나는 구조다.

11. 톤앤매너 원칙

모든 템플릿은 다음 원칙을 따른다.

단정적 예언("반드시 ~하게 됩니다")이 아니라 성향 서술("~한 편이에요")로 쓴다.
부정적 단정("나쁜 사주")을 피하고, 각 패턴의 특징을 중립적·긍정적으로 재해석한다.
문장 길이는 2~3문장, 화면 한 번에 읽히는 분량을 유지한다.
"당신은"으로 시작하는 문장이 반복되지 않도록 버전마다 문장 구조를 다르게 쓴다.

12. 검증 체크리스트

각 카테고리 완성 시 다음을 확인한다.

10패턴 × 2버전 = 20개 템플릿 모두 존재
각 템플릿에 pattern ID 오타 없음(예: bigeob를 biegob로 잘못 쓰는 등)
변수 치환 시 문장이 자연스러운지 {이름} 대입 테스트
동일 패턴의 v1과 v2가 내용상 겹치지 않는지 확인
부정적 단정 표현이 없는지 확인
