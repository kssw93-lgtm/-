문서 목적

본 문서는 「사주 계산 규칙서 v2.0」에서 정의한 계산을 수행하기 위해 필요한 고정 데이터, 매핑 테이블, 관계 데이터 및 외부 검증 데이터의 구조를 정의한다.

본 문서는 해석을 위한 데이터가 아니다.

본 문서의 목적은 다음과 같다.

계산 규칙
+
고정 데이터
+
역법 데이터
+
관계 데이터
↓
동일한 입력
↓
동일한 사주 계산 결과

본 문서에 정의된 데이터는 AI가 임의로 변경해서는 안 된다.

18. 십신 데이터

십신은 일간과 상대 천간의 관계로 계산한다.

관계 유형:

same_element
generated
controlled
generated_by
controlled_by

음양 관계:

same_yinyang
different_yinyang

십신 매핑:

오행 관계	같은 음양	다른 음양

같은 오행	비견	겁재
내가 생함	식신	상관
내가 극함	편재	정재
나를 극함	편관	정관
나를 생함	편인	정인


중요: 이 표는 일간 기준의 생극 관계를 정확히 적용해야 한다.

19. 십신 계산용 기준

일간을 DAY_MASTER라고 정의한다.

예:

DAY_MASTER = 甲

상대 천간:

乙

이면:

甲 = 木陽
乙 = 木陰

같은 오행 + 음양 다름:

겁재

와 같이 결정한다.

십신은 문자열을 AI에게 생성시키지 않는다.

76. 개발 AI에게 전달할 데이터 구축 원칙

Codex 또는 Claude Code는 다음 원칙을 따른다.

DATA-001
본 문서의 고정 데이터를 임의로 변경하지 않는다.

DATA-002
웹 검색 결과를 자동으로 Production 데이터로 사용하지 않는다.

DATA-003
역법 데이터는 원천 출처와 버전을 기록한다.

DATA-004
절기는 날짜가 아니라 정확한 시각을 저장한다.

DATA-005
음양력은 윤달 정보를 포함한다.

DATA-006
일진은 60갑자 index를 함께 저장한다.

DATA-007
천간/지지 index는 0부터 시작하거나 1부터 시작할 경우 전체 프로젝트에서 통일한다.

DATA-008
관계 데이터는 중복을 방지한다.

DATA-009
데이터 변경 시 버전을 변경한다.

DATA-010
계산 데이터와 해석 데이터를 분리한다.

DATA-011
AI가 명리 해석을 근거로 계산 데이터를 변경하지 않는다.

DATA-012
모든 핵심 데이터에 자동 무결성 검사를 적용한다.

DATA-013
1961년 8월 10일 이전 출생자의 시각은 반드시 82번 표준시 이력 데이터를 조회하여 정규화한 뒤 계산한다. 현재 시간대(Asia/Seoul, UTC+9)를 과거 출생자에게 그대로 적용하지 않는다.

80. 최종 핵심 원칙

① 데이터와 계산 공식을 분리한다.

② 계산 데이터와 해석 데이터를 분리한다.

③ 원천 역법 데이터와 Production 데이터를 분리한다.

④ 절기 데이터는 정확한 시각을 저장한다.

⑤ 음양력 데이터에는 윤달을 포함한다.

⑥ 일진 데이터에는 60갑자 index를 포함한다.

⑦ 모든 데이터는 버전 관리한다.

⑧ 외부 만세력 데이터를 그대로 복사하여 정답으로 사용하지 않는다.

⑨ KASI 등 검증 가능한 역법 자료를 우선한다.

⑩ 독립적인 계산 결과와 교차검증한다.

⑪ AI가 데이터나 계산 결과를 임의로 수정하지 않는다.

⑫ 동일한 입력 + 동일한 규칙 + 동일한 데이터 = 동일한 결과를 보장한다.

⑬ 1908년 이후 출생자는 표준시 변경 이력을 먼저 적용한 뒤 계산한다.

82. 대한민국 표준시 변경 이력 데이터 (신설)

본 절은 15번(시지 시간 데이터)과 40번(시간대 데이터)의 기본 표가 "1961년 8월 10일 이후, 서머타임 미시행 기간"에만 그대로 유효하다는 전제를 보완하기 위한 데이터다.

사주는 두 시간 단위(시진)로 시주를 나누기 때문에, 단 1시간의 오차도 자시/축시, 오시/미시 등 경계를 넘겨 시주 자체를 바꿔버릴 수 있다. 따라서 과거 출생자의 계산에는 아래 이력이 필수다.
