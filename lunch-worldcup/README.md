# 오늘의 점심 월드컵 (점심 월드컵)

직장인의 매일 반복되는 "점심 뭐 먹지" 고민을, 이상형 월드컵 방식으로 10초 만에 해결해주는 초간단 유틸리티 미니앱입니다.

- 카테고리: 한식 / 일식 / 중식 / 양식 / 분식 / 매운맛 / 건강식 / 멕시칸 등 16개 메뉴 풀
- 게임 방식: 8강 또는 16강 토너먼트, 두 메뉴 중 하나를 계속 골라 최종 1개 확정
- 결과 화면: 확정 메뉴 + "근처 배달 할인 쿠폰 받기" CTA + 공유하기(Web Share API / 클립보드 복사)

## 추천 이름 후보
- 오늘의 점심 룰렛
- 직장인 메뉴 월드컵
- 메뉴 고민 종결자

현재 화면상 표기는 "점심 월드컵"으로 임시 지정했습니다. 최종 이름 확정 시 `index.html`의 `<title>`/로고 텍스트만 바꾸면 됩니다.

## 로컬에서 확인하기

빌드 도구 없이 순수 HTML/CSS/JS로 만들어서 정적 서버만 있으면 바로 확인 가능합니다.

```bash
cd lunch-worldcup
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속 (모바일 폭 기준으로 디자인됨)
```

## 광고 수익 포인트 (현재는 자리표시자만 구현됨)

| 위치 | 파일/요소 | 설명 |
|---|---|---|
| 상시 배너 | `index.html` `#ad-banner`, 모든 화면 하단 고정 | 배너 광고 SDK 연동 지점 |
| 전면 광고 | `app.js` `renderInterstitial()` | 우승 메뉴가 정해진 직후, 결과 공개 전에 노출되는 전면 광고 자리 |
| 제휴 링크 | `app.js` `COUPON_URL` 상수 | 결과 화면의 "근처 배달 할인 쿠폰 받기" 버튼 클릭 시 이동. 실제 제휴사 링크/딥링크로 교체 필요 |

## 앱인토스(App in Toss) 연동 다음 단계

이번 버전은 앱인토스 SDK 없이 표준 웹 구조로 먼저 만들었습니다. 실제 앱인토스 미니앱으로 전환하는 구체적인 절차(`ait init`/`apps-in-toss.config.ts` 스키마/배포 API 키 관리/광고·공유 SDK 연동 코드)는 [`docs/apps-in-toss-setup.md`](./docs/apps-in-toss-setup.md)에 정리해뒀습니다. 실제 `ait build`/`ait deploy`는 이 샌드박스 세션에서는 콘솔 도메인 접근이 막혀 있어 실행할 수 없으므로, 네트워크 제약 없는 환경(개발자 PC 등)에서 그 문서를 따라 진행하면 됩니다.

## 향후 개선 아이디어
- 메뉴 풀을 지역/시간대(아침·점심·야식)별로 다양화
- "다시 이 메뉴 안 나오게 하기" 필터
- 최근 선택 이력 저장 후 "최근에 또 골랐어요" 안내
- 카테고리 필터(매운맛만/한식만 등) 옵션
